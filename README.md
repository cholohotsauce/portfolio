# arcadiovega.com

Personal portfolio of Arcadio Vega: 15 years in professional kitchens, now building iOS apps.

Live at [arcadiovega.com](https://arcadiovega.com).

- Plain static HTML, CSS and JavaScript in one file (`index.html`). No build step.
- Hosted on Vercel. Every push to `main` deploys to production.
- Vercel Web Analytics and Speed Insights load from `/_vercel/insights/script.js` and `/_vercel/speed-insights/script.js`.
- The site is "Look Closer". Each section has a white side (the kitchen) and a dark side (the developer) under it. A glass lens follows the pointer and shows the dark side. A click or tap on a section opens it fully.
- On touch screens the lens stays near the middle of the screen, so the page scrolls under it. A touch moves it. A Close button shows while a section is open.
- Type `hala madrid` for a short gold theme.
- Copy rule: every claim on the page must come from a project README, a case study or Arcadio. Do not add invented numbers or anecdotes.
- Earlier sites stay online: The Rail at `/rail.html`, the receipt at `/receipt.html` and the iPhone at `/iphone.html`.
- Ace Bartender and Cashout Calculator are web apps today. Do not label them iOS until the native versions ship.
- Project screenshots live in `shots/` as 600px-wide WebP files and appear inside each project's phone frame. WhereWolf replaced GeoWho in October 2026; its repo is private, so its page shows no code link.
